連續登入與解鎖

連續天數啟動順序說明
第 1～3 天A僅轉動輪盤 A
第 4～5 天A → B先轉 A，再轉 B

結算邏輯

  • 依解鎖條件轉動對應輪盤，先 A → 再 B → 再 C
  • 最終獎勵 ＝ A 盤獎項 ×（1 + B 盤百分比）× C 盤倍數
  • 若未解鎖 B 或 C，則不計入該部分加成

  • 若中斷登入，連續天數歸零，重新從第 1 天開始計算
  • 獎勵將直接發送至玩家背包
