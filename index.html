天天登入送

連續登入 · 獎勵加碼

今日首次登入，可免費轉動輪盤！

活動為 7 天一週期，每日首次登入即可啟動 A 輪抽獎，
抽出的獎項會再套用你的遊戲等級加成；
第 4 天起加開 B 輪加成、第 6 天再加開 C 輪乘倍，獎勵越來越豐厚。

活動流程

連續天數流程
第 1～3 天A 輪抽獎 → 套用遊戲等級 → 總結算給獎
第 4～5 天A 輪抽獎 → 套用遊戲等級 → B 輪加成 → 總結算給獎
第 6～7 天A 輪抽獎 → 套用遊戲等級 → B 輪加成 → C 輪乘倍 → 總結算給獎

遊戲等級加成表

結算邏輯

  • A 輪實際基礎獎勵 ＝ A 輪獎項 × 等級加成
  • 最終獎勵 ＝ A 輪實際基礎獎勵 ×（1 ＋ B 輪 %）× C 輪倍數
  • 第 1～3 天未開放 B / C 輪，最終獎勵即為 A 輪實際基礎獎勵
  • 第 4～5 天未開放 C 輪，乘倍以 X1 計
  • 等級加成依玩家當下「遊戲等級」對應層級判定，於 A 輪開獎後立即套用
  • 各段運算結果四捨五入至整數

注意事項

  • 活動時間以伺服器時間為主
  • 每日僅可參與 1 次，需在當日首次登入時啟動，不可補領
  • 左上「遊戲等級」下拉為原型模擬用，可切換層級檢視加成效果
  • 若中斷登入，連續天數歸零，重新從第 1 天開始計算
  • 本模擬固定由第 1 天依序進行到第 7 天，不可跳天；要重跑請按右上「重置天數」
  • 獎勵將直接發送至玩家背包
※ 本頁為互動原型，機率與獎項數值為示意設定，實際以正式版本為準。
